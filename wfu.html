The World Fiscal Uncertainty Index

Daily to annual World Fiscal Uncertainty index, with selected fiscal and policy episodes.

Definition

The World Fiscal Uncertainty index (WFU) is the share of all web news articles processed by GDELT worldwide, in English and in approximately 65 machine-translated languages, that carry at the same time an uncertainty term, an economy term and a fiscal term (taxation, government spending, budgets, deficits or public debt). The share is scaled so that its 2016–2025 average equals 100; a value of 200 indicates that such articles were twice as frequent as on average over the decade. Each article enters the world index once, and the world index is not shrunk (see Methodology).

wfuData = {
  const f = wfuFreq.toLowerCase();
  const rows = await d3.csv(`data/plot/world_${f}.csv`, d3.autoType);
  const when = d =>
    f === "daily" ? new Date(d.DATE) :
    f === "weekly" ? new Date(d.WEEK_START) :
    f === "monthly" ? new Date(Date.UTC(d.YEAR, d.MONTH - 1, 15)) :
    f === "quarterly" ? new Date(Date.UTC(d.YEAR, 3 * d.QUARTER - 2, 15)) :
    new Date(Date.UTC(d.YEAR, 6, 1));
  const lab = d =>
    f === "daily" ? d3.utcFormat("%-d %b %Y")(when(d)) :
    f === "weekly" ? `Week of ${d3.utcFormat("%-d %b %Y")(when(d))}` :
    f === "monthly" ? d3.utcFormat("%b %Y")(when(d)) :
    f === "quarterly" ? `${d.YEAR} Q${d.QUARTER}` : `${d.YEAR}${d.PARTIAL ? " (Jan–Sep)" : ""}`;
  return rows.map(d => ({...d, date: when(d), when: lab(d)}));
}

wfuChart = {
  const start = {"2016 – today": "2015-12-01", "Since 2020": "2020-01-01", "Since 2024": "2024-01-01"}[wfuSpan];
  const x0 = new Date(start), x1 = new Date("2026-10-31");
  const rows = wfuData.filter(d => d.date >= x0);
  const daily = wfuFreq === "Daily";
  const smooth = daily ? Plot.windowY({k: 30, anchor: "middle"}, {x: "date", y: "WFU"}) : {x: "date", y: "WFU"};
  const ymax = d3.max(rows, d => d.WFU) * (daily ? 1.15 : 1.3);
  const ev = wfuEvents.filter(d => d.date >= x0);
  return Plot.plot({
    width, height: 440, marginLeft: 48, marginTop: 10,
    x: {type: "utc", domain: [x0, x1], label: null},
    y: {domain: [0, ymax], grid: true, label: "Index, 2016–2025 average = 100", clamp: true},
    marks: [
      Plot.ruleY([100], {stroke: "currentColor", strokeOpacity: 0.4, strokeDasharray: "4,3"}),
      Plot.ruleX(ev, {x: "date", stroke: "currentColor", strokeOpacity: 0.18}),
      Plot.text(ev, {x: "date", y: d => ymax * (0.98 - 0.075 * d.row), text: "label", fontSize: 10.5,
                     fill: "currentColor", fillOpacity: 0.75, lineWidth: 7, lineAnchor: "top", textAnchor: "middle"}),
      daily ? Plot.lineY(rows, {x: "date", y: "WFU", stroke: "#9ec5f4", strokeWidth: 0.7}) : null,
      Plot.lineY(rows, {...smooth, stroke: "#2a78d6", strokeWidth: 2}),
      Plot.tip(rows, Plot.pointerX({x: "date", y: "WFU", title: d =>
        `${d.when}\nWFU ${d.WFU?.toFixed(1)}  (z = ${d.WFU_Z?.toFixed(2)})\nWEPU ${d.WEPU?.toFixed(1)}\n${d3.format(",")(d.N_W)} articles`}))
    ]
  });
}

Companion world series

The same articles yield world indices of economic policy uncertainty (WEPU, the classification of Baker, Bloom and Davis, 2016), monetary policy uncertainty (WMPU), trade policy uncertainty (WTPU) and sovereign-debt uncertainty (WSDU), all of which are included in the world data files.
