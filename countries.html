Country Indices

Domestic, foreign and all-sources fiscal policy uncertainty indices for 245 economies.

Three measures for each economy

For each economy the indices are computed from three sets of articles: those published by outlets located in the economy (domestic index, DFU), those published by outlets located elsewhere that mention the economy (foreign index, XFU), and all articles that mention the economy (all-sources index, AFU). The domestic index is the counterpart of a national newspaper index; the foreign index measures the external narrative about the economy’s public finances. Each index equals 100 on average over 2016–2025 within its economy, so that it describes movements over time rather than differences in level across economies. Cross-country comparisons of levels should use the shares (_SH) or the standardized series (_Z) in the data files.

cM = d3.csv("data/plot/country_monthly.csv", d3.autoType)
cA = d3.csv("data/plot/country_annual.csv", d3.autoType)
cNames = d3.sort(Array.from(d3.rollup(cA, v => v[0].COUNTRY, d => d.ISO3), ([iso, name]) => ({iso, name})), d => d.name)
viewof cIso = Inputs.select(new Map(cNames.map(d => [`${d.name} (${d.iso})`, d.iso])), {value: "USA", label: "Economy"})
viewof cFreq = Inputs.radio(["Monthly", "Annual"], {value: "Monthly", label: "Frequency"})
viewof cSeries = Inputs.checkbox(cKeys, {value: cKeys.slice(0, 2), label: "Series"})
viewof cLog = Inputs.toggle({label: "Logarithmic scale", value: true})
cKeys = ["Domestic press (DFU)", "Foreign press (XFU)", "All sources (AFU)", "Domestic, stable outlets (DFU_PNL)"]
cCols = ({"Domestic press (DFU)": "DFU", "Foreign press (XFU)": "XFU", "All sources (AFU)": "AFU",
          "Domestic, stable outlets (DFU_PNL)": "DFU_PNL"})
cRows = {
  const src = (cFreq === "Monthly" ? cM : cA).filter(d => d.ISO3 === cIso);
  const date = d => cFreq === "Monthly" ? new Date(Date.UTC(d.YEAR, d.MONTH - 1, 15)) : new Date(Date.UTC(d.YEAR, 6, 1));
  const when = d => cFreq === "Monthly" ? d3.utcFormat("%b %Y")(date(d)) : `${d.YEAR}${d.YEAR === 2026 ? " (Jan–Sep)" : ""}`;
  return cSeries.flatMap(s => src.map(d => ({date: date(d), when: when(d), series: s, value: d[cCols[s]],
                                            thin: d.THIN_D === 1, n: d.N_D})))
                .filter(d => d.value != null && d.value > 0);
}
cChart = Plot.plot({
  width, height: 420, marginLeft: 50,
  x: {type: "utc", label: null},
  y: cLog
    ? {type: "log", grid: true, label: "Index, 2016–2025 average = 100 (log scale)",
       domain: [Math.min(50, d3.min(cRows, d => d.value)) * 0.9, Math.max(200, d3.max(cRows, d => d.value)) * 1.1],
       ticks: [10, 25, 50, 100, 200, 400, 800, 1600], tickFormat: d3.format(",")}
    : {grid: true, zero: true, label: "Index, 2016–2025 average = 100"},
  color: {domain: cKeys, range: ["#2a78d6", "#eb6834", "#1baf7a", "#6250d6"], legend: true},
  marks: [
    Plot.ruleY([100], {stroke: "currentColor", strokeOpacity: 0.4, strokeDasharray: "4,3"}),
    Plot.lineY(cRows, {x: "date", y: "value", stroke: "series", strokeWidth: 2}),
    cFreq === "Annual" ? Plot.dot(cRows, {x: "date", y: "value", fill: "series", r: 4, stroke: "var(--bs-body-bg, white)", strokeWidth: 1.5}) : null,
    Plot.tip(cRows, Plot.pointerX({x: "date", y: "value", stroke: "series", title: d =>
      `${d.when}\n${d.series}: ${d.value.toFixed(1)}${d.thin ? "\n(thin domestic cell: few articles)" : ""}`}))
  ]
})

Figure 1 (interactive). Fiscal policy uncertainty indices for the selected economy, calendar basis. Cells with fewer than 1,000 domestic articles or 10 fiscal uncertainty articles in a month (2,000 and 20 in a year) are noisy even after shrinkage and are flagged in the data (THIN_D, THIN_X, THIN_A). Where the composition of news outlets changes markedly, the stable-outlet series DFU_PNL is preferable (flag COMPBRK_D).

Annual domestic index by economy

viewof rYear = Inputs.range([2016, 2026], {step: 1, value: 2025, label: "Year"})
viewof rThin = Inputs.toggle({label: "Exclude thin cells", value: true})
rTable = cA.filter(d => d.YEAR === rYear && d.DFU != null && !(rThin && d.THIN_D === 1))
  .map(d => ({Economy: d.COUNTRY, ISO3: d.ISO3, DFU: d.DFU, XFU: d.XFU, AFU: d.AFU,
              "Domestic articles": d.N_D, Thin: d.THIN_D === 1 ? "yes" : ""}))
Inputs.table(rTable, {
  sort: "DFU", reverse: true, rows: 15, select: false,
  format: {DFU: x => x?.toFixed(1), XFU: x => x?.toFixed(1), AFU: x => x?.toFixed(1),
           "Domestic articles": x => d3.format(",")(x)}
})

Table 1 (interactive). Annual indices on the calendar basis for the selected year; 2026 covers January–September. Columns can be sorted. A value above 100 indicates fiscal policy uncertainty above the economy’s own 2016–2025 average.
